How we
measure results.

The same method on every project, so results can be compared and checked.

02

One target metric

Each build has one primary KPI and an acceptance threshold agreed in advance.

03

Like for like

We compare similar cases before and after, including review and maintenance time.

04

Monthly report

Results are reported every month against the baseline, with sample size and period.
