THE STARTING POINT

Too many sources,
too much retyping

Real estate agencies in Saudi Arabia work with many developers and a constant flow of new projects. Keeping track of what is available, where it is and who sells it is a data problem, and entering every project by hand does not scale.

We built a portal that puts projects on a map, keeps developers and properties in shared databases and loads new project data automatically.

What we
built

A web portal where agencies find projects by location and work from one shared set of data.

01

An interactive map

Developer projects on a map of Saudi Arabia, with a live list of what is in view and filters by project status and developer.

02

A developer database

Developers with their projects, so an agent sees who is selling what and where.

03

A shared property inventory

Units for sale with prices, sizes, payment plans and documents on one project card.

04

AI-assisted project import

New projects are read by AI, structured and added to the database automatically, instead of being typed in by staff.

05

Tools for agents

Favorites, a personal catalog and messages to the seller, right from the project card.

HOW AI IS USED

AI removes the typing

The slow step was entering project data. AI reads incoming project material, extracts the fields that matter and places them in the right records, so new projects reach the database without manual typing.

  • Project material read and structured automatically
  • Fields placed into the right records
  • New projects reach the database without manual typing
